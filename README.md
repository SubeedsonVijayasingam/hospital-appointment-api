# Hospital Appointment API

## Overview

A hospital appointment management project built with Node.js, TypeScript, Prisma ORM, and PostgreSQL.

## Features

* Patient CRUD operations
* Doctor management
* Appointment booking and cancellation
* Appointment status updates
* Prisma database integration

## Testing

Run the test file using:

```bash
npx tsx src/test.ts
```

## Database Seeding

Run:

```bash
npx prisma db seed
```
